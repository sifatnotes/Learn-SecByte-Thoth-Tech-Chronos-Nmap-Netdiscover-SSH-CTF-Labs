# Learn SecByte Thoth-Tech, Chronos, Nmap, Netdiscover & SSH CTF Labs

A hands-on collection of Learn SecByte cybersecurity and CTF labs covering TCP port scanning, Nmap network discovery, Netdiscover reconnaissance, Thoth-Tech lab setup and enumeration, VirtualBox networking, SSH-to-root exercises, and Chronos command, encoding, node-shell, and binary challenges.

This repository is useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical network and Linux security skills.

## Introduction

The collection follows a progression from network discovery and lab setup into service enumeration, SSH access, command execution, and Linux privilege-escalation concepts.

The supplied URLs explicitly reference **Nmap, Netdiscover, TCP scanning, VirtualBox, SSH, Chronos, encodings, Node shell, and binary analysis**. Difficulty ratings and CVE identifiers are not assumed unless specified by the supplied lab URLs.

## Learning Path

A practical progression through this collection is:

1. **Start with lab setup** using the Thoth-Tech and VirtualBox preparation labs.
2. **Learn network discovery** with Nmap Net Hunt and Thoth Trace: Discovery.
3. **Practice TCP scanning** with Port Storm: Full TCP Sweep.
4. **Use Netdiscover** to strengthen local network reconnaissance skills.
5. **Move into Thoth-Tech SSH** and study the path toward controlled root access.
6. **Begin the Chronos series** with command and encoding-focused exercises.
7. **Explore Node shell concepts** in Chronos Node Shellcraft.
8. **Study binary-focused challenges** with Chronos Bin Breaker.
9. **Finish with the Chronos root-oriented and review challenges** to consolidate the workflow.

## How to Use the Labs

1. Open a lab from the direct-link index.
2. Follow the lab's setup and authorization instructions.
3. Configure the provided virtual environment when required.
4. Begin with host and network discovery.
5. Enumerate ports and services systematically.
6. Record useful findings before attempting access.
7. Use SSH, command execution, encoding, or binary-analysis techniques only against the authorized CTF target.
8. Document commands, observations, and lessons learned.
9. Reset and repeat the environment to improve your methodology.
